# Bulgarian Design Council — design system

The colours, type, spacing and layout the site is built from, and the components
assembled out of them.

---

## Where the values live

Everything here is read from **`app/globals.css`** — the tokens, the type styles,
the breakpoint overrides. These pages parse that file and display what they find,
so a swatch or a size shown here is always the one in the code.

Change a value in `globals.css` and it updates here, in the components, and on
the site together.

If something looks missing from a page, the parser in `design-system/tokens.ts`
needs updating. Values are never typed in by hand.

---

## The pages

**Colour** — brand palette, the semantic names that point at it, and the contrast
each colour affords.

**Typography** — eleven styles, live specimens, and how sizes resolve across
screen widths and reader text-size settings.

**Space and radius** — the four spacing steps and one radius, drawn at true size.

**Layout and breakpoints** — the grid, gutter and rail, and what changes at each
breakpoint.

**Components** — each story sits beside the component it documents.

| --- | --- |

| Phone, last pixel · 767 | 4 |
| Tablet · 8 col · 768 | 8 |
| Tablet, last pixel · 1023 | 8 |
| Desktop · 12 col · 1024 | 12 |

---

## Two things to know before editing

**Type sizes work two ways.** Above 768px they scale fluidly with the viewport.
Below 768px they switch to fixed sizes set in a separate block. To change how
headings look on phones, edit that block — the fluid values won't affect them.

**Column count is a variable.** `--grid-cols` drives `.bdc-grid`, `.bdc-stop-11`
and the overlay, so one change moves the whole page together. Setting
`grid-cols-12` directly on an element breaks that link.
